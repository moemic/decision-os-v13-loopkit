# Private tool-return intake checklist — synthetic draft

Source: `source/intake_facts.md`. This is a local volunteer draft, not a
certified safety procedure or public instruction.

1. **Received / logged:** Accept the returned tool. Record its item ID and
   return time in the local ledger. A ledger entry means only that the item
   was received and logged.
2. **Inspection pending:** Leave condition status unresolved until a second
   volunteer checks it. The source does not supply inspection criteria, so
   this checklist cannot say what the check must contain or that any item
   passed it.
3. **Available to lend:** Use this state only after the item has been
   inspected and placed on the lending shelf. Do not infer this state from
   the ledger entry alone.

Do not use the single label `ready` for both a ledger entry and availability.
If the inspection result or shelf placement cannot be established, keep the
item out of the `available to lend` state and mark the missing fact `UNKNOWN`.

Before operational use, Mira must supply the actual inspection criteria and
confirm that this sequence matches the desk's practice.
